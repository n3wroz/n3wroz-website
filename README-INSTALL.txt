N3WROZ INTERACTIVE — WEBSITE DEPLOYMENT

This is a static website prepared for deployment through GitHub + Render.

UPLOAD
1. Extract this ZIP on your computer.
2. Open the contents of the N3WROZ_POFRA_Website folder.
3. Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
   index.html, assets/, en/, es/, ar/, about/, products/, etc. must be at repository root.
4. Do not upload the ZIP itself or an extra enclosing N3WROZ_POFRA_Website folder.
5. Commit the changes. Render should deploy from the connected repository automatically.

IMPORTANT
- Keep the existing GitHub repository and Render service; replace only repository files.
- A backup of the current repository is recommended before replacing files.
- Legacy /privacy-policy/ and /terms/ paths redirect to the Turkish policy and terms pages.
- Canonical and hreflang links use https://n3wroz.com.tr. Confirm that this domain is connected to Render before relying on those URLs for indexing.
- This package does not itself publish or configure your domain, DNS, or Render service.
